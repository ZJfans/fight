# 《暮色边境》V1.3 · 战术沉浸迭代版

> **实际可玩但未完成商业品质。** 原创单人俯视角战术撤离游戏。本版本由 V1.2 的原始源码继续开发而来，不是美术概念图。它使用原创几何世界、8 方位预渲染角色贴图；可选程序化三维人物网格。*没有使用真实商业级 PBR 扫描人物 GLB 和完整骨骼动作库。*

## 启动

- 推荐直接打开发布目录的 `暮色边境_立即试玩.html`，无需外网或安装。较新 Chrome/Edge/Safari。
- 或者运行 `python -m http.server 8000`，访问 `http://localhost:8000/index.html`。
- ZIP 为可修改的完整源码。没有依赖 npm / 外网 CDN；可以交给 Godot/Unity 团队作游戏设计与数据参考，但不是 Godot 工程。

## 核心目标

在废弃工业禁区潜入，回收三份情报，绕开敌人或交战，穿过警戒线到西侧撤离。三次情报回收触发 2+2+1 敌人增援，撤离后给出战绩与等级。可重试。

## V1.3 本轮增量

1. **真正三维几何地图的材质改良**：从本项目原创地图概念图提取纹理细节，加工为 16 格工业表面图集。WebGL2 GPU 使用纹理采样；软件兼容渲染不支持该纹理效果。
2. **方向光阴影通道**：新增 1536×1536 阴影深度图 + PCF 柔和遮挡，绘制静态建筑和动态人物的阴影。*本环境未能验证 GPU 实际显示，需要玩家浏览器验收。*
3. **双人物可视化**：8 向真人风格预渲染贴图添加分段步态、姿态缩放、翻滚与后坐力反馈；P 可切换至三维实体人形（程序化关节运动）。三维人形仍是低面数临时资产，不是写实商用角色。
4. **战术道具**：Q 烟雾遮挡 AI 视野，T 捕兽夹使敌人受伤并短时定身；有库存、冷却/存续时间、界面按钮。与手雷、治疗、弹药管理共同构成战术选择。
5. **AI**：整合烟幕视线判定、玩家冲刺/蹲伏引发的差异化发现速度、陷阱触发、巡逻、报警、增援。
6. **离线运行**：贴图和模型预渲染贴图都已经嵌入单文件 HTML。

## 开发结构

- `index.html`: 页面和 HUD 结构
- `src/render.js`: WebGL2 三维渲染管线、材质、阴影、软件兼容器
- `src/world.js`: 战场地形、工业建筑、集装箱、可穿行路径和掩体
- `src/game.js`: 状态机、战斗、人物动态、AI、烟幕、陷阱、撤离
- `src/style.css`: 端游/触屏 HUD、菜单、结算
- `assets/industrial_material_atlas.webp`: 原创工业纹理拼图
- `assets/operative_0..7.webp`: 原创 8 方位人物图
- `assets/lobby_operative.webp`: 菜单角色图
- `build.py`: 重新构建完全离线的单文件 HTML
- `tests/`: Playwright 的检查脚本（需要安装 Playwright 包及 Chromium）
- `tools/build_atlas.py`: 图集生成脚本（需要 Pillow / numpy，源概念图在原会话附件）

## 测试和限制

请阅读 `TEST_REPORT.md`。自动化测试在受限制的 Chromium 中运行，WebGL 被禁用，因此显示结果是软件兼容渲染。**不能以软件渲染的截图证明 GPU 阴影和 PBR 材质成功通过验证**。测试中的三任务通关采用了仅在 e2e 模式下开放的位移钩子，验证的是任务系统，不是正常玩家能无伤通关。

## 许可/素材

使用本次对话生成的原创角色和场景美术，不打包《求生之战》游戏原有素材、LOGO、角色等受保护资源。若后续需要真正写实人物 GLB/FBX 与骨骼动画，优先选择 CC0/明确可商用的 CC-BY 资产，保留作者署名与许可；当前离线环境无法自动下载和验证此类外部模型文件。
