# 《暮色边境》V2.8 港区美术样板升级说明

## 本轮目标
在 **V2.7 原项目** 上继续修改，不扩展玩法，不破坏已有 **移动、射击、交互、撤离** 功能。优先完成出生点附近港区样板区的视觉统一与战斗可读性。

## 已完成内容

### 1. 港区样板区域（出生点附近）
- 在出生点附近新增并打磨了一块 **道路 + 小型仓储附属房 + 掩体交战区** 的样板区域。
- 补入了：
  - 模块化仓储附属房（厚门框、窗框、屋顶）
  - 装卸区地面边线与编号喷涂
  - 路缘、排水沟、装卸棚、路灯、货物小车、托盘、桶、板条箱
  - 交战掩体（混凝土隔离墩、沙袋、临时遮棚）
- 所有新增元素均使用现有低多边形工业风语言构建，避免与原有风格割裂。

### 2. 材质与配色统一
- 调整整体调色到 **冷灰 / 灰绿 / 暗蓝** 主基调。
- 保留暖黄灯光作为点缀与导视。
- 重新平衡了：地面、水泥、金属、屋顶、玻璃、容器与角色装备的颜色关系。
- 降低了过亮、偏蓝、过于“平铺棋盘格”的观感。

### 3. 灯光与空间层次
- 调整 Web 版渲染器基础清屏色与点光源布局。
- 让出生点附近样板区有更明确的：
  - 主冷色环境光
  - 局部暖色实用灯
  - 屋顶与墙体的明暗分层
- 保持战斗可读性优先，没有用重雾或过强 Bloom 遮盖模型。

### 4. 角色与武器反馈
- 保留原有 GLB / 低多边形角色流程。
- 增强枪口火光、命中/弹着、粉尘/火花等反馈。
- 未改动核心武器逻辑，三把武器、切枪、射击、换弹、撤离测试通过。

### 5. HUD 收敛与统一
- 收紧了顶部与底部 HUD 的尺寸、边距与视觉重量。
- 降低噪点层、压缩调试感，保留：
  - 生命值
  - 护甲/体力
  - 武器与弹药
  - 交互与撤离相关提示
- 新增战术状态文字（暴露 / 潜行 / 交火 / 撤离中）用于快速读图。

### 6. 遮挡处理
- 为样板区新增的屋顶/装卸棚采用了 **动态屋顶层** 方案。
- 玩家进入对应覆盖范围时，屋顶将自动隐藏，避免遮挡人物与近距离战斗观察。

### 7. 性能与实现方式
- 未引入高面数角色包或大量动态灯。
- 仍以现有 WebGL / 软件兼容渲染链为基础。
- 重点增加的是 **中低成本的模块化场景细节**，而不是昂贵特效堆叠。

## 实测保留功能
已实际测试并确认以下功能仍可正常工作：
- 开始游戏
- WASD 移动 / 右键自动寻路（原逻辑保留）
- 左键射击
- 1/2/3 切枪
- R 换弹
- E 交互回收三份情报
- 前往撤离点成功结算

## 最终资产 / 占位资产

### 本轮可视为“最终资产方向”的部分
- 出生点附近港区样板区的模块化风格
- 调整后的整体配色方向
- 新的装卸区地面喷涂 / 路缘 / 掩体 / 路灯 / 小货物车等低多边形视觉语言
- 新的 HUD 收敛风格
- 动态屋顶隐藏逻辑

### 仍属于占位 / 过渡性质的部分
- 大地图其余区域仍有较多旧版地面与旧密度配置，尚未全部按样板区标准铺开
- 玩家与敌人的角色模型仍沿用当前版本资源，没有全面重做人物 silhouette
- 部分大型建筑外立面仍偏简化，需要后续继续按同样标准逐区翻新
- 网页版软件回退渲染仍无法完全等同 WebGL 视觉表现

## Web 与 Godot 差异
当前这轮的高完成度样板区主要先落在 **web_playable** 版本中，差异如下：

1. **Web 版**
   - 已实装：样板区布局、动态屋顶隐藏、HUD 收敛、战斗特效增强、局部灯光分布与材质配色调整。

2. **Godot 侧**
   - 保留了原有可用的 Godot 4 资源目录与 GLB 资源：
     - `assets/characters/*.glb`
     - `assets/weapons/*.glb`
     - `assets/modules/*.glb`
   - 但样板区的全部场景细化与渲染表现 **尚未完整一比一同步进 Godot 场景文件**。
   - 也就是说：**资源保留可用，但本轮网页样板区效果不应直接视作 Godot 场景已完全同步验收。**

## 本轮实际测试的渲染方式
- 实测通过：**软件兼容渲染（software-perspective-approx）**
- 同时保留 WebGL 路径；实际视觉效果在支持 WebGL 的浏览器中会更好。
