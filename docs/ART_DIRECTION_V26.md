# 《暮色边境》V2.6 美术方向 — 潮汐港区 / Tidal Dock

## 参考目标
用户上传的俯视战术射击场景只用于确定审美方向，不作为游戏的背景贴图。所有可交互地物在浏览器分支内以 3D 网格构建，Godot 分支以原生 MeshInstance3D / StaticBody3D 构建。

## 视觉语言
- 主基调：冷蓝/蓝青工业地坪，深色钢材，少量暖黄色警戒标线。
- 相机：正交近俯视，兼顾空间可读性与人物身体轮廓；网页试玩使用约 68° 俯角；Godot 工程配置约 75°。
- 场景锚点：带卷帘门仓库、集装箱、货盘、隔离护栏、道路标记、装卸机械和可遮挡射线的混凝土掩体。
- 地面识别：SK-23、04 等实体网格拼接字样，货运斜纹带、排水格栅及磨损纹理。
- 人物：延用 V2.4 原创 18 骨骼/6 动画 GLB，加入较易识别的亮度校正和适度比例调整；仍非写实角色。
- HUD：默认简洁；H 切换电影模式，Tab 展开完整任务信息。

## 美术验收边界
这不是用户图片的逐像素复刻。当前工业模型以几何模块和程序化材质为主，局部细节、接触阴影、复杂 PBR 和角色质量尚未达到参考画面的品质。不得把此版本称为商业级画质。
