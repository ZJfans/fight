# 《暮色边境》V2.9 港区视觉样板与资源同步

**基础版本**：V2.8（继承自 V2.7），未新开游戏工程；核心单局目标与敌人 AI 保留。

## 这次实际修改

1. **工业港区样板**：细化出生点附近样板（约 x=3–27 m，z=8–23 m）；完整可进入仓储附属房的分段墙、2.6 m 中央门洞、窗框和玻璃、门头、雨棚、檐口、屋顶肋条、侧管线、地坪排水沟、路缘、标线、货盘、货车、混凝土掩体、沙袋和暖色工业灯。**实体墙提供碰撞，门洞保持畅通；装饰物不无故增加实体墙。**
2. **统一美术**：削弱蓝色地坪大面积随机明暗方块，改为低变化地面板与低密度伸缩缝。冷灰、灰绿、暗蓝主色，暖黄导视色。
3. **材质**：新制 7 类 512×512 的原创漫反射贴图与对应粗糙度贴图；游戏 WebGL 自有图集更新为细颗粒材质。Godot 原生艺术模块脚本在导入时按构件功能设置 PBR 材质并绑定贴图。
4. **光影**：软件回退增加低开销的脚底接触暗影、掩体附近暗影和暖色灯池（均为软件近似）；现有 WebGL 阴影映射代码保留。无浓雾/强泛光。
5. **角色与武器**：保留既有 18 骨骼原创人物，读取 `Weapon` 骨骼挂点与三把武器 GLB 的 `Muzzle` 节点，将枪口火光与弹道的显示起点对齐；射击、换弹、蹲伏、跑步动画逻辑不改。
6. **反馈**：根据弹着表面选择克制的粉尘、金属火花或木屑粒子，有限数量和寿命。
7. **HUD**：保留血量、弹药、战术状态、交互、撤离；隐藏面向开发者的 GLB 按钮，收紧手机端顶部信息，减少遮挡。
8. **遮挡**：新仓储附属房屋顶、檐口与 20 个屋顶细节可单独隐藏；进入建筑时隐藏屋顶，不牺牲门口可通行性。

## Web / Godot 的真实差异

| 方面 | Web 试玩版 | Godot 4 原生工程 |
|---|---|---|
| 样板仓库 | 已实例化并在 Chromium 软件兼容模式运行 | 新建 `scripts/harbor_sample_art.gd`，在 `IndustrialSet` 原地图自动实例化相同 GLB 模块 |
| 资产 | 几何由 V2.8 世界模块加细，动画独立 GLB | 5 个新的模块化 GLB + 原有角色及三枪 GLB；在原工程中加载 |
| 材质 | 更新 4×4 灰度 atlas；WebGL 路径未获运行验证 | 7 类 PNG PBR albedo 与 roughness，在艺术模块中赋予材质（运行未验证） |
| 屋顶 | 进入样板区域通过 JavaScript 隐藏 20 片屋顶 | 脚本 `update_viewer` 控制独立 GLB 屋顶显示（未通过引擎运行） |
| 枪口挂点 | Web 端解析角色 Weapon 骨骼与三把枪的 Muzzle 节点，实际浏览器验证坐标 | Godot 仍沿用旧版近似挂枪位置，**未完成同等 Socket 绑定验收** |
| 地图 | 保留原约 110 × 100 m 港区与三份情报撤离 | 仍为旧版 42 × 34 m 原生演示地图，本轮在其中加入同风格局部样板；**整张地图没有 1:1 同步** |
| 任务流程 | 原有收集 3 份情报、撤离完整保留；实测通过 | 原生工程仍以清除敌人演示为主，不能冒充 Web 完整任务已移植 |

## 文件与资源

- `assets/characters/operative.glb`：约 1.8 m、18 骨骼，`Tpose/Idle/Walk/Run/Crouch/Aim/Shoot/Reload` 8 段动画；旧版原创资产，本轮保留并改用真实挂点。
- `assets/weapons/DF_WPN_R07_Rifle.glb` / `DF_WPN_S12_Shotgun.glb` / `DF_WPN_M01_Pistol.glb`：每把均有命名 `Muzzle` 节点；旧版原创资产。
- `assets/modules/DF_ART_HarborAnnex_Walls.glb`：可进入建筑的门窗、结构、管线，尺寸约 10.23 × 5 × 10.56 m。
- `assets/modules/DF_ART_HarborAnnex_Roof.glb`：独立屋顶与肋条，尺寸约 10.1 × 0.4 × 8.34 m。
- `assets/modules/DF_ART_ConcreteCover.glb`：约 3.88 × 1.45 × 1.16 m。
- `assets/modules/DF_ART_PalletSupply.glb`：约 1.45 × 0.89 × 1.38 m。
- `assets/modules/DF_ART_DockLight.glb`：约 2.72 × 5.53 × 0.68 m。
- `assets/materials/DF_MAT_*_{albedo,roughness}.png`：7 类材料，每图 512 × 512。
- `scenes/harbor_art_sample.tscn`：单独打开的 Godot 样板预览场景，**未经引擎运行测试**。
- `tools/build_v29_assets.py`：本轮原创模型与贴图生成源码。

全部新增资产由本轮原创生成，无需借用其他游戏的版权素材。角色与三枪沿用旧版项目中原创资产。

## 最终程度与仍待打磨

**可复用的视觉样板组件**：仓库、独立屋顶、混凝土掩体、货盘与路灯、低饱和材质规范、HUD 收敛、真实碰撞门洞与动态屋顶隐藏实现。

**仍属占位或未完成**：其余区域部分原有建筑、工厂细节与材质尚未全部统一；人物装备高精度细节及完整动画分层融合还未达到专业美术水平；非样板区的 Web 与 Godot 地图仍不同；浏览器 GPU 阴影、Godot 实际导入与执行尚无法在本环境验证。不能据此宣称商用品质或全地图最终美术完成。

## 测试环境及限制

- Chromium headless 1280 × 768 / 390 × 844。环境中无法创建 WebGL2，即使尝试 SwiftShader/ANGLE 标志也失败，因此**实测画面是 Canvas 软件兼容渲染，不等于 GPU 材质与阴影验收**。
- 已使用浏览器实际加载内联 HTML，进行进入战场、切枪/开火、进出样板仓库门洞与屋顶隐藏、收集三份情报、撤离，以及真实触摸事件移动和射击。
- 本地文件 URL 导航受执行环境管理员策略限制，因此**没有直接双击本地文件测试**。交付 HTML 已内嵌游戏脚本、模型、贴图，无外部依赖，预期可由一般桌面浏览器打开。
- 当前环境未安装 Godot 引擎，无法编译/运行原生工程；实际 GDScript 解析、角色武器挂点与场景碰撞仍需在 Godot 4 打开后确认。
