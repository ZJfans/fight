# V2.6 立即试玩

在 Windows、macOS 或 Linux 上解压项目后可双击 `web_playable/暮色边境_立即试玩.html`，也可以直接打开顶层单独交付的 HTML 文件。无运行时网络依赖；旧版浏览器可能不兼容。推荐新版 Chrome/Edge。

## 操作
- 点击「进入战区」，WASD/方向键移动，鼠标移动瞄准，左键开火，右键点击地面寻路。
- Shift 冲刺、X 蹲伏、C 翻滚、R 换弹、1/2 切换武器。
- F 治疗、G 手雷、Q 烟幕、T 陷阱，E 拾取情报/撤离。
- H 切换极简 HUD、Tab 展开任务列表、Z/V 转换视角、滚轮缩放。
- 手机使用左侧虚拟摇杆与右侧射击/装备操作区。
- 目标：在港区找齐三份情报，抵达西侧撤离点，E 完成结算。

## 架构说明
HTML 是基于历史浏览器战斗工程维护的独立可玩分支，不是 Godot Web 导出；ZIP 中的 `project.godot` 是对应的原生 Godot 4 工程，包含主要场景和 3D 资产。两者暂未完全实现功能一致。
